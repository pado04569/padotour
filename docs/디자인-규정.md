# 여행의 파도 홈페이지 디자인 규정

정리일: 2026-10-11 · 대상: 10/8 이후 UX 개편 작업(작업지시서 v2 ~ 최종 QA, 파비콘)
표기: **(사장님 MM/DD)** = 사장님이 직접 정하신 것. 표기 없는 줄 = 작업지시서를 구현하면서 정한 코드 기준값.
색 토큰은 `src/app/globals.css` 의 `@theme` 에 있다. 새 화면은 hex를 직접 쓰지 말고 토큰을 쓴다.

## 1. 글자 정렬

### 기본
- 본문·목록·상품 정보·일정표·폼은 **왼쪽 정렬**한다.
- 안내·문의를 권하는 **카드는 내용 전체를 가운데 정렬**한다. 제목·설명·버튼 모두 `text-center`. **(사장님 10/10)**
- 가운데 정렬 카드 안의 버튼은 화면 폭만큼 늘리지 않는다. 내용 너비로 두고 `mx-auto` 로 가운데에 놓는다. **(사장님 10/10)**
- 같은 성격의 상자는 정렬을 통일한다. 하나만 왼쪽이면 안 된다. **(사장님 10/11 "왜 이것만 중앙정렬이 아니야?")**

### 화면·요소별
| 화면·요소 | 정렬 |
|---|---|
| 페이지 제목 띠(Hero) | 회사소개는 가운데(`text-center`). 나머지는 왼쪽 |
| 검색 결과 하단 크림 카드 "찾으시는 상품이 없나요?" | 가운데 **(사장님 10/10)** |
| 결과 0개·가까운 출발일 아래 카카오 카드 | 가운데 **(사장님 10/10)** |
| 일반 상품 목록 아래 초록 문의 띠 | 가운데(`justify-center text-center`) |
| 상품 상세 "예약 문의 · 맞춤 견적" 상자 | 제목·설명 가운데 **(사장님 10/11)** |
| 꼬리말 사업자 정보 | 휴대폰(<768px)은 가운데, PC는 왼쪽 **(사장님 10/10)** |
| 메인 "지금 떠나기 좋은 골프여행" 제목+보조문구 | 기존 제목 위치 유지 **(사장님 10/10)** |

## 2. 줄바꿈 (한글)
- 전체(body)에 `word-break: keep-all; overflow-wrap: break-word;` 를 건다. 단어 중간에서 끊기지 않는다. **(사장님 10/10 지시서)**
- 제목 h1~h3에는 `text-wrap: balance` 를 건다. 두 줄 길이를 고르게 맞추는 설정이다.
- 기기 폭에 맞춘 `<br>` 하드코딩은 금지한다. **(사장님 10/11)**
- 짧은 의미 덩어리는 `whitespace-nowrap` span으로 묶는다. 예: "확인 후 견적을 전달드립니다", "여행의 파도"(NBSP).
- nowrap 덩어리는 **20자 이내**로 한다. 길면 375px에서 화면 밖으로 넘친다(10/11 QA 항공편 사례).
- 줄을 끊어도 되는 자리에는 `<wbr>` 를 넣는다. 예: "/" 뒤, "(" 앞, 가운뎃점 "·" 뒤.
- 꼬리말 사업자 정보는 휴대폰에서 의미 단위로 줄을 나눈다(상호·대표·사업자번호 / 관광사업등록번호 / 주소 / 이메일). **(사장님 10/10)**
- 가운데 정렬 안내문은 휴대폰에서 자연스럽게 2줄이 되게 쓴다. **(사장님 10/10)**
- 375 / 390 / 430px에서 가로 스크롤 0개, 화면 밖으로 나가는 요소 0개여야 한다(QA 기준).

## 3. 여백·간격
- 페이지 좌우 여백은 `px-4` = **16px**이다(휴대폰·PC 공통).
- 본문 최대 폭은 `max-w-6xl` = **1152px**이다. 읽는 글은 `max-w-3xl`(768px)~`max-w-4xl`(896px).
- 제목 띠 위아래 여백은 `py-10 md:py-12` = 40px / PC 48px이다.
- 후기 페이지 제목 띠는 휴대폰 높이를 15~20% 줄였다. `py-7 md:py-12` = 28px / PC 48px. **(사장님 10/10)**
- 메인 제목과 상품 카드 사이 여백을 과하게 벌리지 않는다. **(사장님 10/10)**
- 꼬리말 맨 아래 여백은 `pb-[calc(44px+env(safe-area-inset-bottom))]` 이다(10/10 휴대폰 하단 여백 축소).
- 휴대폰 폼은 입력칸과 버튼을 세로로 쌓는다. 간격 10~12px, 둘 다 폭 100%. 내 예약/문의 화면에 해당한다. **(사장님 10/10)**
- 가까운 출발일 버튼은 **2열 × 최대 2행(최대 4개)** 이다. 빈칸을 채우려고 가짜 날짜를 넣지 않는다. **(사장님 10/10)**

## 4. 버튼 크기
- 터치 영역은 최소 **44px**(`min-h-11`)이다. 50~60대 고객 기준.
- 메인 "전체 상품 보기"와 "골프장 전체보기"는 **같은 크기**이다. `max-w-[340px] min-h-[52px]`, 알약형(`rounded-full`), 테두리 2px. **(사장님 10/10)**
- 정렬 탭(추천순·가까운 출발일순·낮은 가격순)은 3칸 균등, 높이 `min-h-[46px]`, 글자 15px이다.
- 휴대폰 떠 있는 상담 버튼은 48×48px(`w-12 h-12`), PC는 56×56px(`md:w-14`)이다. 크기를 줄이지 않는다. **(사장님 10/11, B안 제외)**
- 주요 행동 글자를 10~11px로 쓰지 않는다. 상품 카드 칩 글자는 최소 13px.
- 버튼 글자는 한 줄로 쓴다. 두 줄로 꺾이면 문구를 줄인다.

### 역할별 규칙
- **가격**은 차분한 빨강 **#D33F3F** 이다(카드 `text-[#D33F3F]`, 상세 `text-red-600`). 파랑·초록으로 바꾸지 않는다. **(사장님 9/29, 10/10 유지)**
- 특가·혜택 배지만 코랄 빨강 **#E84B4B** 을 쓴다. 일반 정보 배지에 빨강을 쓰지 않는다. **(사장님 10/10)**
- 출발지·신규·"인기"·"3색골프" 배지는 파랑(`bg-brand-blue`) 흰 글자이다. **(사장님 10/10)**
- 국가 배지는 모든 나라가 같은 `accent-teal` 이다. 나라마다 색을 바꾸지 않는다. **(사장님 10/10)**
- 인원 배지 "[2인부터]"는 기존 회색을 유지한다. 강조형만 크림 `#FFF7DC` / 글자 `#765A16` 이다. **(사장님 10/10)**
- 선택된 정렬 탭은 `brand-blue` 바탕에 흰 글자이다. 선택 안 된 탭은 흰 바탕, 글자 #17233B, 테두리 #D9E1EA. **검정 선택 상태는 금지.** **(사장님 10/10)**
- "왜 여행의 파도인가요?" 노란 포인트는 유지한다(체크 아이콘 #E0B800). **(사장님 10/10 "1. 유지")**
- 검색 결과 문의 카드는 크림색 `bg-yellow-50` 이다(가운데 정렬). **(사장님 10/10)**
- 꼬리말 빠른상담 아이콘 4개는 파랑 계열 하나로 맞춘다. 카카오라고 노랑을 세게 쓰지 않는다. **(사장님 10/10)**
- 떠 있는 상담 버튼 바탕은 #011C41 이다.

## 6. 제목 띠 (페이지 Hero)
- 제목 띠 색은 두 토큰만 쓴다. 페이지별로 hex를 직접 넣지 않는다. **(사장님 10/11, 3안)**
  - `hero-commerce` **#008F78**: 상품을 고르는 곳. 골프여행 상품 목록, 지역 띠.
  - `hero-info` **#007F73**: 읽고 확인하는 곳. 골프장 소개, 골프장 상세, 후기, 내 예약/문의, 공지/이벤트, 회사소개.
- 회사소개 첫 화면은 #007F73 이다. 파랑으로 되돌리지 않는다. **(사장님 10/11)**
- 헤더·꼬리말·로고·주요 행동 버튼은 제목 띠 규칙과 상관없이 `brand-blue` 를 유지한다. **(사장님 10/11)**
- 상품 목록 제목 띠에는 IconFlag 선 아이콘을 붙인다. 제목 앞 이모지는 쓰지 않는다. **(사장님 10/11)**
- 첫 화면(랜딩)은 L1이다. 풀스크린 골프장 사진 Hero + 출발공항 카드 2개 구성. 대한민국 지도형·탑승권형은 쓰지 않는다. **(사장님 10/10)**
- 랜딩 로고는 흰색 단색 로고를 사진 위에 직접 놓는다. 원·글래스·박스로 감싸지 않는다. 사진과 겹칠 때만 약한 그림자나 위쪽 어두운 그라데이션을 쓴다. **(사장님 10/10, D2)**

## 7. 아이콘
- **OS 기본 이모지(✈️📅🌙⛳👥📞💬 등)는 화면 UI에 쓰지 않는다.** 고객이 쓴 후기 본문 속 이모지는 그대로 둔다. **(사장님 10/10·10/11)**
- 아이콘은 `components/icons/MenuIcons.tsx` 하나만 쓴다. 선 굵기 1.8, `currentColor`, 기본 20px(요약 카드 아이콘 칸은 32px `h-8`). **(사장님 10/11)**
- **새 아이콘 라이브러리는 추가하지 않는다.** 필요하면 MenuIcons.tsx에 같은 스타일로 그려 넣는다. **(사장님 10/11)**
- 아이콘 대응: 가는 편=PlaneTakeoff, 오는 편=PlaneLanding, 출발일=CalendarDays, 문의=MessageCircle/Phone, 뒤로=ArrowLeft. **(사장님 10/10 지시서)**
- 화살표는 공통 IconChevron / SelectChevron 이다. 노란 삼각형은 쓰지 않는다. **(사장님 10/9)**
- 출발공항 카드 아이콘은 작은 대한민국 지도(KoreaMiniMap)이다. 비행기가 아니다. **(사장님 10/10)**
- 파비콘은 사장님이 주신 파란 원 안의 흰 P(#005DC9)이다. 16·32·48px ico와 512px png로 넣었다. 전체 PADO 로고로 되돌리지 않는다. 헤더 로고는 그대로 둔다. **(사장님 10/11)**

## 8. 카드·테두리
- 상품 카드는 `rounded-2xl`(16px), 흰 바탕, `shadow-md`(마우스를 올리면 `shadow-xl`)이다.
- 상품 카드 요약은 칩으로 보여 준다. 칩은 높이 28px(`h-7`), `rounded-lg`, 글자 13px. **(사장님 10/10)**
- 상품 대표 사진은 항상 골프장 사진이다. 밝은 컷을 쓰고 보정이나 어두운 덮개를 씌우지 않는다. **(사장님 9/29·10/3)**
- **테두리 박스를 남발하지 않는다.** 네모 칸이 여러 개 겹치면 지저분해 보인다. **(사장님 10/9)**
- 같은 기능의 버튼이나 링크를 한 화면에 두 번 두지 않는다. 예: SGI 보증보험과 여행사등록 중복, 회사소개와 "왜 여행의 파도인가요?" 중복. **(사장님 10/9·10/10)**
- 지역 지도 버튼은 흰 바탕 + 초록 테두리 + 작은 지도 그림 + 한 줄 설명이다. 초록으로 꽉 찬 버튼은 쓰지 않는다. **(사장님 10/9)**
- 문의 카드는 화면당 1개만 둔다.
  - 검색 결과가 있을 때만 목록 아래 크림 카드를 둔다.
  - 결과가 없을 때는 안내와 카카오를 카드 1개로 합친다.
  - 초록 문의 띠는 검색하지 않은 일반 목록에만 둔다. **(사장님 10/10)**
- 회사소개는 대표자의 말 중심이다. "여행의 파도가 약속하는 것" 카드와 파란 문의 상자는 없앴다. **(사장님 10/10)**

## 9. 휴대폰 / PC 차이
| 항목 | 휴대폰 (<768px) | PC (≥768px) |
|---|---|---|
| 떠 있는 상담 버튼 | 내리면 숨김, 멈추고 0.7초 뒤 표시, 올리면 바로 표시. 상담 버튼·꼬리말이 화면에 보이면 숨김 **(사장님 10/11, A+C)** | 항상 표시(기존 그대로) |
| 내 예약/문의 폼 | 입력칸·버튼 세로로 쌓기, 폭 100% **(사장님 10/10)** | 가로 한 줄 |
| 꼬리말 사업자 정보 | 가운데 정렬, 의미 단위 줄바꿈 **(사장님 10/10)** | 왼쪽 |
| 지역 지도 | 지역 버튼 위의 접힌 토글 버튼 **(사장님 10/9)** | 같은 펼침 버튼(N3) **(사장님 10/10)** |
| 조건 바꾸기 | 아래에서 올라오는 시트 | 가운데 창 |
| 후기 목록 | 1열 | 2열 **(사장님 10/10)** |
| 랜딩 로고 | 현재 크기 | 로고 20~30%, 브랜드명 15~20% 크게 **(사장님 10/10)** |
| 검색창 | 전체 폭 | 기존보다 5% 좁게 **(사장님 10/9)** |
| 휴대폰 메뉴 순서 | 공지/이벤트 → 여행후기 → 골프장 소개 → 대표자의 말 → 카카오톡 → 등록·보증 **(사장님 10/11)** | 헤더 그대로 |

- 화면을 확인할 폭은 375 / 390 / 430 / 1280 / 1440px이다.

## 10. 문구 (디자인과 함께 정한 것)
- 응답 시간을 약속하는 말("바로", "즉시", "빠르게")은 쓰지 않는다. **(사장님 10/11)**
- 견적 안내는 "확인 후 견적을 전달드립니다."로 쓴다. 아래 버튼과 겹치는 "맞춤"은 뺐다. **(사장님 10/11)**
- 상품 상세 문의 버튼 글자는 "견적 문의하기"이다(제목과 같은 말을 반복하지 않는다). **(사장님 10/11)**
- 입력칸이 없는 항목(예: 예산)을 안내문에 쓰지 않는다. **(사장님 10/11)**
- 후기 요청 문구는 "여행을 다녀오신 후, 소중한 이야기를 함께 공유해 주세요"처럼 쓴다. "여행"을 반복하지 않는다. **(사장님 10/11)**
- 표기는 "나라별"이 아니라 "국가별"이다. **(사장님 10/10)**

## 국가별 상품 페이지 탐색 구조 (사장님 작업지시 2026-10-25)

- 국가 지도는 본문 전체 폭(연결선 없음·좌표 유지), 열고 닫아도 선택 지역 유지
